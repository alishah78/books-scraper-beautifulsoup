# Books Scraper (BeautifulSoup)

This project scrapes book data from books.toscrape.com using 
BeautifulSoup and exports it to a professionally formatted Excel file.

## Tools Used
- Python
- Requests
- BeautifulSoup (HTML parsing)
- Pandas
- OpenPyXL

## Features
- Multi-page scraping (pagination across 50 pages)
- Data cleaning (removing currency symbols, converting to proper numbers)
- Duplicate removal
- Error handling for failed page requests
- Professional Excel export with bold headers

## Output
Generates a clean Excel report containing 900+ book listings with 
Title, Price, and Stock Availability.
